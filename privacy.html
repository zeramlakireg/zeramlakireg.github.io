Privacy policy

Last updated: 5 September 2026

Mariner Assistant Backup is a Windows backup utility maintained by its owner for personal use. This policy covers the backup utility and this information website.

Data used for backup

The utility packages selected personal assistant configuration, instructions, writing preferences, skills, support code and documentation. Credentials, email, vessel folders, indexes and caches are excluded from the archive.

Google OAuth credentials are used locally to connect the owner's Google account. Backup status and verification records are kept locally to identify completed backups and errors.

Google permission and use

The utility requests only Google Drive app-data access (drive.appdata, called drive.appfolder by rclone). It creates, lists, uploads and downloads files in the application's hidden data area for backup and recovery. It does not request access to ordinary Drive files, Gmail or contacts.

Google provides the cloud storage. Data obtained through Google access is used only for this backup and recovery function. It is not sold, used for advertising or sent to AI APIs by the backup job.

Protection and retention

Backup contents and the checksum sidecar are encrypted with rclone crypt before upload. File and folder names are not encrypted. Local connection credentials are protected for the current Windows user using Windows DPAPI.

Retained local ZIP archives are not encrypted. The utility retains at most two of its own local backup archives, with a combined limit of 100 MiB. Temporary processing can use additional space.

Cloud backup versions remain in the Google account until removed by the owner or the storage provider. The utility does not automatically delete cloud versions. Recovery requires the original encryption password and access to the same Google account and application.

Removing access and data

The owner can revoke the application's access through the Google account's connected-app settings. Revocation stops further authorized access but does not erase files already copied to the computer or cloud.

The owner can remove the application's stored data through Google's app-data controls and remove local backup archives separately. Deleting app data removes cloud backups and can prevent recovery. Google's app-data documentation explains this storage area and its deletion behaviour.

Website hosting

This website has no sign-in, forms, scripts, analytics or advertising trackers. It does not receive backup contents or Google credentials.

When served through GitHub Pages, GitHub logs visitors' IP addresses for security, as described in its hosting documentation. Google and GitHub handle data within their services under their respective Google privacy policy and GitHub privacy statement.

Contact

For support or privacy enquiries, use the user support email shown on the Mariner Assistant Backup Google OAuth consent screen.
