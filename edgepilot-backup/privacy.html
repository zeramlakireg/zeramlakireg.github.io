Privacy policy

Last updated: 7 September 2026

EdgePilot Archive Backup is a Linux backup utility maintained by its owner for personal use. This policy covers that utility and its information pages under /edgepilot-backup/. It does not replace the separate Mariner Assistant Backup policy.

Data handled and purpose

The utility reads and uploads only the existing project archives and accompanying manifests admitted for a particular backup. These files can contain project artifacts and inventories, including file names, paths, sizes and content hashes. The owner must review the selected material before approving transfer; the utility is not a general sensitive-content scanner.

Google account identity and storage-quota information are used to confirm the intended destination and available capacity. File identifiers, sizes, checksums, versions and access-permission metadata are used to verify uploads and detect unexpected changes. Local status and verification records describe the backup and any failures.

Google API data is used only for the owner's backup, verification and recovery functions, in accordance with the Google API Services User Data Policy and its Limited Use requirements. The utility does not sell this data, use it for advertising or AI training, or send backup contents to AI APIs.

Google permission and storage

The utility requests only https://www.googleapis.com/auth/drive.file. This gives access to files created by the app or specifically authorized for it, not unrestricted access to the account's Drive. It does not request Gmail, contacts or hidden application-data access. Google's Drive permission documentation describes the scope.

Backups are stored in ordinary folders in the owner's Google Drive account, not in a hidden application-data folder. The utility creates private, owner-only destinations and checks those permissions during verification. It does not create public links or grant sharing access. The owner or provider can subsequently change access or remove data.

The OAuth permission includes the ability to edit or delete app-authorized files. That permission is broader than the operations performed by this copy-only utility, which does not automatically overwrite or delete cloud files.

Transfer protection and local connection records

Google API connections use HTTPS. The current utility uploads the approved files as they already exist; it does not add password-based or client-side encryption. Their names and contents are not concealed from Google by this utility. No end-to-end encryption claim is made.

The utility keeps its OAuth client configuration, access and refresh tokens, and upload-session restart records in owner-restricted local files. These records are sensitive and are not uploaded as backup payloads or published on this website. The current Linux setup relies on filesystem permissions; it does not claim that these local records are password-encrypted.

Original archive bytes are streamed without staging another local archive. Small local progress records bind the session to the approved source and destination. Recovery checks Google's acknowledged position before continuing, and stops if required state is missing, expired or inconsistent.

Verification and retention

The utility checks original content hashes and reads back complete uploaded files to compare their SHA-256 hashes. Only a completed verification record establishes that this particular copy passed those checks. App registration, a visible filename or an interrupted transfer is not sufficient proof.

Cloud versions remain until the owner or storage provider removes them. This utility does not automatically prune cloud history or delete local originals. Local credentials and operational records are retained for connection, restart and audit until separately reviewed and removed by the owner.

There is no two-package or 100 MiB retention rule in this EdgePilot utility. Those rules belong to a different backup application. Frozen project files remain subject to their own preservation and retirement requirements. This utility does not establish immutable storage or guarantee complete system recovery.

Removing access and data

The owner can revoke EdgePilot Archive Backup through the Google account's third-party connection controls. Revocation stops further authorized access; it is not a request to erase previously uploaded ordinary Drive files or local copies.

The owner can manage visible backup files through Google Drive and remove local connection records separately. Deleting or emptying the trash for the only usable backup can prevent recovery. Any removal of original frozen records requires a separate reviewed decision.

Retain the Google account identity, client recovery information and backup recovery instructions in a secure recovery kit outside the PC. Do not publish this material with the information pages.

Information website and providers

These information pages contain no sign-in form, upload form, JavaScript, analytics or advertising trackers. They do not collect backup contents or Google credentials. Only the public information pages and their stylesheet are published here.

Google provides account authorization and backup storage. GitHub Pages hosts this information site and logs visitor IP addresses for security, as described in its hosting documentation. Each provider handles data within its services under its own Google privacy policy or GitHub privacy statement.

Contact and updates

For support or privacy enquiries, use the user support email configured for EdgePilot Archive Backup and shown during Google authorization. This policy must be updated if the utility's permissions, encryption, storage or retention behavior changes.
