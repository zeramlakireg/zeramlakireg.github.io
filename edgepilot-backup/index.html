Private, visible project backups

EdgePilot Archive Backup is an owner-operated Linux utility for copying selected existing project archives and their verification manifests to the owner's Google Drive account.

It is maintained for personal use, not as a public sign-up service. It is separate from Mariner Assistant Backup and does not manage that application's hidden backup data.

How it works

  1. The owner approves the exact files and connects the intended Google account.
  2. The utility checks the originals and uploads them to an ordinary, private Drive folder. The folder and completed files are visible in the owner's Google Drive app and website.
  3. It reads back the complete uploaded files and compares their SHA-256 hashes with the approved originals, while checking the destination's identity and private access.

Transfers stream the existing files without creating another local archive. Small private restart records allow status-checked continuation when Google still accepts the saved upload session. Missing, expired or inconsistent restart information stops the transfer for review.

The utility runs when invoked by the owner; this setup does not install a scheduled backup task, mount a drive or activate EdgePilot services.

Limited Google access

The only requested Google permission is https://www.googleapis.com/auth/drive.file. This permits access to files created by the app or specifically authorized for it, rather than unrestricted access to all Drive files. The utility uses this access for backup creation, inspection and retrieval; it does not request Gmail, contacts or hidden app-data access.

The Google permission includes editing and deleting app-authorized files. The current backup utility does not automatically overwrite or delete cloud files or local originals, and it does not share the backup folder.

Protection and recovery

Transfers use HTTPS. The current utility copies the existing archive bytes without adding password-based or client-side encryption. A private, visible folder is not a promise of end-to-end encryption.

Completed backups can be downloaded through Google Drive. Original files remain in place; removing frozen project records requires a separate reviewed decision. A cloud copy alone is not an immutable-storage or complete system-recovery guarantee.

Publishing this information site or completing Google sign-in does not prove that a backup succeeded. A successful transfer requires its own completed upload and full verification record.

Privacy and support

The privacy policy explains the data handled, local connection records, retention and removal of access.

For support or privacy enquiries, use the user support email configured for EdgePilot Archive Backup and shown during Google authorization. Never send passwords, OAuth tokens or client-secret files in a public message.
